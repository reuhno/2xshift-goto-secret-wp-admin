2xShift Goto secret wp-admin

Fonctionnement

Un double appui sur la touche Shift (moins de 275 ms) redirige vers l'accès admin caché d'un site WordPress ; la règle utilisée est mémorisée par hôte, avec une proposition par défaut pour les nouveaux sites.

Si un cookie de connexion WordPress est présent, aucune redirection n'a lieu : rester connecté suffit à ne jamais déclencher la redirection par erreur.

Afin de ne pas faire de redirection inopinée sur un site qui nécessiterait d'appuyer plusieurs fois sur la touche Shift rapidement, le script détecte si le site sur lequel nous naviguons est bien un site WordPress en vérifiant la présence de chaines wp-content wp-includes ou wp-admin dans le code source de la page.

Réglages

Décochée : la proposition par défaut s'applique sans demander.

Ajoute redirect_to à l'adresse de connexion. Peut être modifié site par site.
